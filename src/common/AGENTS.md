# common/ AGENTS

- 대상 테스트: 계약 U-COM-01, 02, 04, 07, 10, 18, 21, 26, 29, 32, 38, 40 · 기능 E-ER-06, 08, 13, 14, E-KA-03~05, E-PX-03, 05.
- include 가능한 다른 디렉토리 헤더: `core/str.h`, `core/buf.h`.
- 함정:
  - TCP는 바이트 스트림이다. 같은 입력을 한 번에, 1바이트씩, 두 조각으로 넣어도 결과가 같아야 한다 (U-COM-02, U-COM-33).
  - CL + TE 동시, 서로 다른 CL 여러 개는 request smuggling 통로다. 관대하게 고르지 말고 400.
  - chunked 크기는 16자리를 넘으면 오버플로우다. `remaining` 계산에서 uint64_t를 넘지 않게.
  - 응답 framing은 요청 메서드(HEAD)와 상태(1xx·204·304)에 따라 달라진다.
- 경계 타입(`types.h`) 변경은 인터페이스 변경 절차로만.
- 작업을 나눌 때는 파일 단위로.
