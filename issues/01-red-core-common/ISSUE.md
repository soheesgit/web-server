# [RED] core + common 기반 구현

## 목적

서버가 공용으로 쓰는 문자열·버퍼·설정·로그·플랫폼 함수와 요청·응답이 공유하는 HTTP 처리 규칙을 구현한다.

## 범위

- `src/core/`의 문자열 뷰, 버퍼, 설정, 로그, 플랫폼
- `src/common/`의 헤더 처리, 본문 길이와 경계 판단, keep-alive, 상태 문구와 오류 본문

## 작업 항목

- [x] `core/`와 `common/`의 공개 인터페이스에 맞춰 공용 기능을 구현했다.
- [x] 버퍼 상한과 실패 시 원상태 유지, HTTP 헤더·본문 경계, 파일 구간 전송을 계약 테스트로 확인했다.
- [x] 추가 계약 테스트를 등록하고 디렉토리별 README를 갱신했다.

## 완료 조건

- [x] `U-CORE-*` 및 `U-COM-*` 대상 계약 테스트가 통과했다.
- [x] 통과한 기존 대기 테스트 ID를 `tests/pending.txt`에서 제거했다.
- [ ] PR에 `make lint`, `make test`, Linux `make asan` 결과를 기록한다.

## 후속 검증

`E-CF-02`, `E-CF-04`와 공용 HTTP 처리에 의존하는 E2E는 앱과 연결 모듈이 연결되면 검증한다. 대상 계약 테스트 ID는 각 모듈 README에 있다.
